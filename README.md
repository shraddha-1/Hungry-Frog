# Hungry Frog 🐸

A WebGPU-based frog-catching game built with HTML, CSS, JavaScript, and WebGPU.

No dependencies. No build step.

## Play

Once published with GitHub Pages, you can play the game here:

**https://shraddha-1.github.io/Hungry-Frog/**

## Run Locally

You can run the game using either:

### VS Code Live Server

Open `index.html` in VS Code and use the **Live Server** extension.
